Memory Leak Harness

Use this page with Chrome DevTools → Performance/Memory to watch for retained nodes after churn. Start/stop loops, then take heap snapshots.

DevTools quick steps
  • 1) Open DevTools → Memory → Allocation sampling.
  • 2) Start a churn (list or mount), record 5–10s, stop.
  • 3) Stop churn, hit garbage collect, record again.
  • 4) Watch detached nodes/listeners; they should not grow.
